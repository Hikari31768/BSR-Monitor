# 歌单-Playlist

玩家可以创建歌单，并向其中添加谱面来对谱面进行归类。

歌单可以在 BeatSaver 网页上创建，也可以在游戏内直接创建。

游戏内创建的歌单以 .bplist 文件（ json 格式，老版本的歌单文件其实用的就是 .json 后缀）保存在本地，可以作为一种批量上传的手段来编辑 BeatSaver 中的线上歌单； BeatSaver 中的线上歌单也能以 .bplist 文件下载下来，导入游戏来进行使用。

BeatSaver 中的线上歌单分为以下类型：

- 手动维护。歌单中的谱面由歌单创建者手动增删。创建者可以设置该歌单是公开还是仅自己可见。
- 通过筛选器生成。借助 BeatSaver 的筛选器生成的歌单，这类歌单是实时更新的，每次访问都是基于筛选设置的最新结果。此类歌单必定是公开的。
- 谱师歌单。由某位谱师发布或参与的谱面都会在这个歌单里面，无需手动创建，每个谱师都会有这样的一个歌单。
