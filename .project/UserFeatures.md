# 用户功能概览

## 🎯 打谱查询
- **单谱面模式**：输入 key 或 hash 查询单个谱面
- **歌单模式**：选择已添加的歌单，分页批量查询（每页100）
- 表格展示 `(谱面, 模式, 难度)` 维度下各玩家的分数，仅显示有得分的难度，无分难度折叠展示
- 歌单模式支持正/倒序切换
- 自由添加/拖拽/删除玩家列
- 点击封面播放音频预览，悬停 Map Key 复制 `!bsr` 命令
- 非当前版本分数标记 🕒

## 👤 玩家管理
- 卡片网格展示玩家，显示分数数量
- 添加玩家（ID + 可选直播地址/备注名），实时进度追踪
- 增量更新分数，支持删除

## 📋 歌单管理
- 卡片网格展示歌单，显示封面和谱面数量
- 通过 BeatSaver 歌单 ID 添加/更新，逐页进度追踪
- 查看歌单内谱面列表，支持删除

## 全局
- 侧边栏导航：Logo、三个页面入口、音量滑块、版本号
- 暗色主题 + 红色强调色
- 通用组件：难度标签、模式图标、弹窗、加载指示器、空状态
