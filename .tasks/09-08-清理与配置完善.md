# 09-08 - 清理与配置完善

## 优先级：P3（收尾阶段）

## 背景

08-05（Tauri 配置）、08-09（通用组件）Review 中发现的配置不完善、冗余文件、占位符等问题。

## Review 问题来源

- [08-05-Tauri主配置Review.md](08-05-Tauri主配置Review.md)
- [08-09-通用组件Review.md](08-09-通用组件Review.md)

## 具体任务

### 1. Tauri 配置

- [ ] `capabilities/default.json` 中 `windows: ["main"]` 引用了窗口 label `"main"`，在 `tauri.conf.json` 中窗口配置显式设置 `label: "main"`
- [ ] CSP 配置：在 `tauri.conf.json` 中设置基础 Content Security Policy，如 `"default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'"`
- [ ] `tauri.conf.json` 中 `$schema` URL 与 `capabilities/default.json` 统一为同一版本格式
- [ ] 依赖版本锁定：`Cargo.toml` 中 `tauri`、`tauri-build`、`tauri-plugin-shell` 从 `"2"` 锁定到具体小版本（如 `"2.0"` 或 `"2.1"`）
- [ ] `Cargo.toml` 中 `authors = ["you"]` 更新为实际作者信息
- [ ] 确认 `tauri.conf.json` 中 `version` 与 `Cargo.toml` 中的 version 管理策略

### 2. 插件清理

- [ ] 评估 `tauri_plugin_shell` 是否真正被使用：
  - 如果未使用：从 `Cargo.toml` 移除依赖，从 `lib.rs` 移除插件注册，从 `capabilities/default.json` 移除 `shell:allow-open` 权限
  - 如果计划使用：在代码中实现对应功能

### 3. 图标资源清理

- [ ] 确认以下图标文件的用途：
  - `64x64.png` — 未被 bundle 配置引用
  - `icon.png` — 未被 bundle 配置引用
  - `StoreLogo.png` — Windows Store 相关，如不需要则删除
  - `Square*Logo.png` — Windows Store 相关
- [ ] 如果不需要 Windows Store 打包，清理冗余图标文件
- [ ] 如果需要，配置对应的 bundle 条目

### 4. 版本号动态化

- [ ] `Sidebar.tsx` 中硬编码的 `v0.1.0` 改为从 Tauri 配置读取
- [ ] 方案：通过 Tauri 命令 `get_version` 返回 `env!("CARGO_PKG_VERSION")`，或前端通过 `@tauri-apps/api` 获取
- [ ] 删除硬编码的版本字符串

### 5. Vite 配置完善

- [ ] `vite.config.ts` 评估是否需要引入 Tauri Vite 插件
- [ ] 确认 `@tauri-apps/api` 模块类型在 `vite-env.d.ts` 中显式声明
- [ ] 构建产物路径与 Tauri `beforeBuildCommand` 配置一致

### 6. 导航与路由联动

- [ ] `Sidebar.tsx` 中 `navItems` 数组从路由配置动态生成，而非硬编码
- [ ] 方案：从 `react-router` 的路由配置中提取导航项，或使用共享常量数组同时用于路由和导航

### 7. `progress.rs` 清理

- [ ] `ProgressPayload::new` 中初始 stage 设为 `"initial"`，但命令层从未发射此阶段事件
- [ ] 要么删除 `"initial"` 初始值（改为空字符串），要么在命令开始任务前发射一次 initial 事件
- [ ] `with_player_info` 拆分为 `with_player_name` 和 `with_player_avatar_url` 两个方法，或让参数接受 `Option<String>`

### 8. `ModeIcon` 修复

- [ ] SVG 图标路径：将 `icons/` 目录下的文件移动到 `public/icons/` 目录，确保 Vite 构建能正确引用
- [ ] `onError` fallback：图标加载失败时显示 `modeNames[mode]` 缩写文本而非空白
- [ ] `modeNames` 重复：删除 `ModeIcon.tsx` 内部的 `modeNames` 映射，从 `src/constants/index.ts` 导入
- [ ] `mode` prop 类型约束：改为 `keyof typeof modeIcons` 或单独的类型定义

### 9. 文档更新

- [ ] `.project/docs/Commands.md`：更新 `MapScoresResponse` 字段名（`no_score_diffs`）、`PlayerScoreCell` 结构、`get_playlist_scores` 参数签名
- [ ] `.project/docs/API.md`：更新序列化默认值说明、难度枚举
- [ ] `.project/docs/Database.md`：更新外键约束、事务保护说明、复合索引
- [ ] `.project/docs/Progress.md`：更新 `TaskType` 枚举
- [ ] `.project/DevGuide.md`：更新开发/构建指引
