# 最终目标

一个本地运行的应用，用户可以持久性地保存一些 BeatLeader 玩家、歌单，也可以临时性地输入谱面的 key ，然后用户就能查看指定玩家对谱面的游玩情况。

初步打算基于 Tauri 来开发这个应用，轻量、易用。

# 本次目标

现在先不要急着进行实际的开发，我们先一起敲定要使用的 API 以及数据库结构，毕竟数据是整个应用的基石。

# 已有进度

目前我自己已经确定了一些接口和数据库表，我们在此基础上继续工作。

## 接口

### BL

[BeatLeader API](../API/bl-api.yaml)

#### get /player/{id}/scores/compact

按日期倒序拉取玩家所有成绩，每页拉100条

```
CompactScoreResponseResponseWithMetadata
    data
        score
            accuracy                // 0.9273462
        leaderboard
            id                          // "4b302xx91" 可以从中得到 key、版本、难度、模式
            songHash
            modeName        // "Standard"
            difficulty              // 9
```

#### get /player/{id}

```
name
avatar
id
```

### Saver

[BeatSaver API](../API/saver-api.yaml)

#### get /maps/id/{id}

```
MapDetail
    id                          // key
    metadata
        songName
    stats
        score                 // 玩家评分
    versions
        hash
        diffs
            characteristic  // Standard OneSaber NoArrows 90Degree 360Degree Lightshow Lawless Legacy
            difficulty          // Easy Normal Hard Expert ExpertPlus
        coverURL
        previewURL      // 音频预览
```
