## 具体任务

### 1. Modal 无障碍访问修复（P0 from 08-09）

- [ ] 添加 `role="dialog"` 属性
- [ ] 添加 `aria-modal="true"` 属性
- [ ] 添加 `aria-labelledby` 指向标题元素
- [ ] 实现 Escape 键关闭：监听 `keydown` 事件，按 Escape 时调用 `onClose`
- [ ] 实现焦点陷阱（focus trap）：
  - 弹窗打开时将焦点移入弹窗内
  - Tab 键在弹窗内循环（不会跑到背景元素）
  - 关闭时恢复之前的焦点
- [ ] 点击遮罩层外部（`bg-black/60` 区域）触发 `onClose`
- [ ] 关闭按钮添加 `aria-label="关闭"`
- [ ] 使用 `ReactDOM.createPortal` 将弹窗渲染到 `document.body`（如尚未使用）

### 2. 其他组件无障碍访问

- [ ] `LoadingSpinner.tsx`：添加 `role="status"` 和 `<span className="sr-only">加载中...</span>`
- [ ] `DiffBadge.tsx`：添加 `title={difficulty}` 或 `aria-label={difficulty}`
- [ ] `Sidebar.tsx` 音量滑块：添加 `aria-label="音量控制"`
- [ ] `Sidebar.tsx` 导航 emoji 图标：添加 `aria-hidden="true"` 并在链接文本中隐藏屏幕阅读器可读的标签
- [ ] `EmptyState.tsx`：添加 `role="status"` 或 `aria-live="polite"`

### 3. 表单验证与反馈

**3.1 玩家管理**

- [ ] 玩家 ID 输入框添加格式校验：`^\d+$`（纯数字），实时显示验证状态
- [ ] 添加必填标记（红色 `*`）和格式提示（"请输入 Steam ID"）
- [ ] 添加按钮 `disabled={!addForm.id.trim()}`，提供视觉反馈
- [ ] 移除 `alert()` 提示，改为内联错误提示或 Toast

**3.2 歌单管理**

- [ ] 歌单 ID 输入框：改为 `type="number"` 或添加正则校验，拦截非数字输入
- [ ] 添加必填标记和格式提示
- [ ] 添加按钮同样添加 `disabled` 状态
- [ ] `isProcessing` 的 `alert` 提示改为内联提示或 Toast

### 4. 用户体验改进

**4.1 玩家更新进度追踪**

- [ ] `Players.tsx` 中 `handleUpdateScores` 添加进度状态管理（`loading`、`progress`、`status_message`）
- [ ] 与添加玩家的进度追踪体验保持一致（显示进度条）

**4.2 歌单更新按钮**

- [ ] `PlaylistCard.tsx` 中添加"更新"按钮，触发对已存在歌单的增量更新
- [ ] 按钮样式与玩家卡片上的更新按钮一致

**4.3 拖拽排序视觉反馈**

- [ ] `ScoreTableHeader.tsx` 拖拽排序添加 drop indicator（高亮目标位置、插入线）
- [ ] 添加 `onDragOver` 时的目标高亮样式或拖拽占位符
- [ ] 触屏设备始终显示删除按钮（不依赖 hover）

**4.4 错误提示优化**

- [ ] `ScoreTable.tsx` 中 `alert()` 替换为内联错误提示或 Toast 组件
- [ ] `Playlists.tsx` 中 `alert()` 同样替换
- [ ] 单谱面模式下，如果 `selectedPlayers` 为空，输入框显示禁用状态 + 提示"请先选择玩家"

**4.5 歌单谱面弹窗优化**

- [ ] `MapCard` 在歌单谱面弹窗中使用紧凑版布局（缩小封面 `w-16 h-16`、减少间距、简化信息）
- [ ] `pm.map` 为 `undefined` 时显示"谱面信息缺失 (key: {pm.map_key})"占位提示
- [ ] 删除确认弹窗中补充说明影响范围（"删除歌单不会移除已下载的谱面文件"）

**4.6 `progress` 与 `undefined` 区分**

- [ ] `Players.tsx:66` 中 `player.progress || 0` 改为 `player.progress ?? 0`（使用 nullish coalescing）

### 5. 键盘导航

- [ ] `PlaylistSelect` 自定义下拉添加键盘导航：方向键选择、Enter 确认、Escape 关闭
- [ ] 添加 ARIA 属性：`role="listbox"`、`aria-expanded`、`aria-activedescendant`
