# 本次目标

完成项目初始化，搭建 Tauri + React + TypeScript 开发骨架，配置 SQLite 数据库插件，并创建数据库表结构。

# 具体任务

## 1. 创建 Tauri 项目

- 使用 `create-tauri-app` 初始化项目
- 选择 React + TypeScript 模板
- 确认项目结构正确

## 2. 配置 SQLite 插件

- 添加 Tauri SQLite 插件依赖
- 配置 `tauri.conf.json` 权限
- 测试数据库连接

## 3. 创建数据库表

根据 [.project/Database.md](../.project/Database.md) 设计，创建以下表：
- Map
- MapDiff
- PlayerInfo
- PlayerScore
- Playlist
- PlaylistMap

## 4. 基础目录结构

规划前端代码目录结构，如：
- `src/api/` - API 调用封装
- `src/db/` - 数据库操作封装
- `src/components/` - React 组件
- `src/pages/` - 页面

# 验收标准

- 项目能正常启动（`npm run tauri dev`）
- SQLite 插件可用
- 数据库表创建成功，可通过简单查询验证
- 目录结构清晰，后续开发有明确路径
