### 1. 难度颜色统一

**1.1 确定权威色值**

- [ ] 以 `tailwind.config.js` 中 `bs.difficulty` 定义为权威色值：

  - `ExpertPlus`: `#c084fc` (purple-400)

**1.2 替换各处硬编码颜色**

- [ ] `DiffBadge.tsx`：移除内联 style 中的 `#347e55`、`#2f66a0`、`#b15c11`、`#a83922`、`#7049ae`，改为使用 Tailwind `difficulty.*` 类名
- [ ] `ScoreRow.tsx`（如保留）或 `MapScoreGroup.tsx` 中的难度颜色逻辑

### 3. CSS 变量与 Tailwind 配置对齐

- [ ] `src/index.css` 中定义的 CSS 变量（`--color-bg-primary` 等）与 `tailwind.config.js` 中的 `bs.*` 主题色存在重复
- [ ] 方案选择：
  - 方案 A：保留 CSS 变量，Tailwind 配置通过 `theme()` 函数引用 CSS 变量
  - 方案 B：保留 Tailwind 配置，删除 CSS 变量定义，组件中统一使用 Tailwind 类名
  - **推荐方案 B**：更符合 Tailwind 惯用法，减少一层抽象
- [ ] 如选方案 A，需确保 Tailwind 配置中 `colors` 使用 `var()` 引用，组件中使用 CSS 变量（`style={{ background: 'var(--color-bg-primary)' }}`）或 `@apply` 工具类

### 4. 其他样式问题

- [ ] `CoverWithAudio.tsx` 中 SVG 进度环 `stroke="#7c3aed"` 改为使用 CSS 变量或 Tailwind 类名
- [ ] `::selection` 的 `rgba(255, 107, 107, 0.3)` 改为 `color-mix(in srgb, var(--color-accent-primary) 30%)`
- [ ] `Sidebar.tsx` 导航 emoji 图标（🎯👤📋）替换为 SVG 图标组件
- [ ] `EmptyState.tsx` 默认 emoji `📭` 替换为 SVG 图标
- [ ] `index.css` 中 `@keyframes fadeIn` 和 `@keyframes slideUp` 考虑替换为 Tailwind v4 的 `@theme` 自定义动画
- [ ] `body` 的 `overflow-y: auto` 与 `Layout.tsx` 中 `h-screen overflow-hidden` 冲突，移除无用声明
