# 07-00 打谱查询页面

新增"打谱查询"页面，作为整个应用最核心的页面，置于导航首位。

## 功能概述

页面支持两种模式：
- **单谱面模式**：直接输入 key 或 hash 查询单个谱面
- **歌单模式**：从已添加的歌单中选择，批量查询歌单内谱面

无论何种模式，主体内容为一个表格，展示所选谱面各难度下各玩家游玩情况。

## 前端实现

### 页面布局

- 顶部：模式切换（单谱面 / 歌单）
- 模式区域：
  - 单谱面：输入框，支持 key 或 hash 输入
  - 歌单：下拉选择已添加的歌单
- 主体：成绩表格

### 表格结构

| 列 | 内容 |
|---|---|
| 谱面信息列 | 封面缩略图、歌名、谱师 |
| 玩家列（可多个） | 各难度下的 accuracy（如有） |
| 操作列 | 加号按钮，用于添加玩家 |

**行组织**：
- 每行对应一个 `(谱面, 模式, 难度)` 组合
- 只有任意一名所选玩家有分数的难度才会成行显示
- 其他难度收纳显示在谱面信息区域
- 谱面内难度行间距弱化，谱面间分隔强化

### 难度排序

按模式编号排序，Legacy（编号 0）放最后：

```
Standard Easy → Normal → Hard → Expert → ExpertPlus
OneSaber Easy → ...
NoArrows Easy → ...
90Degree Easy → ...
360Degree Easy → ...
Lightshow Easy → ...
Lawless Easy → ...
Legacy Easy → ...
```

### 难度显示

| 难度 | 缩写 | 颜色 |
|---|---| ---|
| Easy | E | #347e55 |
| Normal | N | #2f66a0 |
| Hard | H | #b15c11 |
| Expert | Ex | #a83922 |
| ExpertPlus | E+ | #7049ae |

### 模式图标

- 各模式用图标表示
- 图标存放在 `icons/` 目录
- 已有图标：standard, onesaber, noarrows, 90degree, 360degree, lightshow, lawless, legacy

### 玩家列管理

- 表头：头像 + 名字
- 鼠标悬停显示删除按钮
- 支持拖拽调整顺序
- 最后一列为空列，表头显示加号按钮，点击弹窗选择玩家

### 单元格内容

- 有分数：显示 accuracy（百分比）
- 无分数：空白
- 非当前版本分数：accuracy + 🕒 图标标识

### 输入识别

- 输入长度 ≤ 39：视为 key
- 输入长度 = 40：视为 hash
- 输入后自动拉取谱面信息，更新数据库，刷新显示

### 分页

- 歌单模式：每页 100 张谱面
- 单谱面模式：不涉及分页

### 路由调整

- 打谱查询页面作为首页（路由 `/`）
- 删除现有"谱面查询"页面（`src/pages/MapSearch.tsx`）

## 后端实现

### 新增命令

| 命令 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `get_map_scores` | key, player_ids | MapScoresResponse | 查询单个谱面在指定玩家下的成绩 |
| `get_playlist_scores` | playlist_id, page, player_ids | PlaylistScoresResponse | 查询歌单某页谱面在指定玩家下的成绩 |

### MapScoresResponse 结构

```typescript
interface MapScoresResponse {
  map: Map;                    // 谱面基本信息
  current_diffs: MapDiff[];    // 当前版本所有难度
  scores: ScoreRow[];          // 成绩数据
}

interface ScoreRow {
  mode: string;
  difficulty: string;
  is_current_version: boolean; // 是否当前版本
  scores: {
    player_id: string;
    accuracy: number;
    is_current_version: boolean; // 该玩家此分数是否当前版本
  }[];
}
```

### PlaylistScoresResponse 结构

```typescript
interface PlaylistScoresResponse {
  playlist: Playlist;
  page: number;
  total_pages: number;
  maps: MapScoresResponse[];
}
```

### 查询逻辑

1. 通过 key 获取谱面所有版本 hash（MapDiff 表）
2. 当前版本：取 `isCurrent = true` 的 hash，获取完整难度列表
3. 旧版本：通过 PlayerScore 表查询是否有分数，合并到对应难度行
4. 跨版本合并：玩家玩过任意版本的某难度，即视为玩过该难度，非当前版本标记 🕒

### 分页计算

- 总谱面数 / 100 = 总页数
- 按 mapOrder 排序
- 返回指定页的谱面列表
