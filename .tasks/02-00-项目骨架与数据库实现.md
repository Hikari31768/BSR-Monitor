# 最终目标

一个本地运行的应用，用户可以持久性地保存一些 BeatLeader 玩家、歌单，也可以临时性地输入谱面的 key ，然后用户就能查看指定玩家对谱面的游玩情况。

# 本次目标

搭建项目骨架，实现数据库 schema。

# 具体任务

1. 初始化 Tauri 项目
2. 配置 SQLite 数据库
3. 实现 6 张表的 schema（Map、MapDiff、PlayerInfo、PlayerScore、Playlist、PlaylistMap）
4. 编写 Rust 数据库操作模块基础结构
