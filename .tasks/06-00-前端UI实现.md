# 最终目标

一个本地运行的应用，用户可以持久性地保存一些 BeatLeader 玩家、歌单，也可以临时性地输入谱面的 key ，然后用户就能查看指定玩家对谱面的游玩情况。

# 本次目标

实现前端 UI，完成用户交互功能。

# 具体任务

1. 创建页面路由结构
2. 实现玩家管理页面：
   - 玩家列表展示（卡片形式，显示头像、名称、成绩数量）
   - 添加玩家（输入 ID，可选填写 liveURL、alias）
   - 删除玩家（确认对话框）
   - 更新成绩（增量更新按钮）
3. 实现歌单管理页面：
   - 歌单列表展示（卡片形式，显示封面、名称、谱面数量）
   - 添加歌单（输入 BeatSaver 歌单 ID）
   - 删除歌单（确认对话框）
   - 查看歌单谱面列表
4. 实现谱面查询页面：
   - 输入谱面 key 或 hash 查询
   - 展示谱面详情（封面、歌曲名、作者、评分、预览音频）
   - 展示难度列表
5. 实现成绩查询页面（核心功能）：
   - 选择玩家（下拉或从玩家列表点击）
   - 输入谱面 key 或 hash
   - 展示该玩家对该谱面各难度的成绩（accuracy、时间）
   - 若玩家未游玩该谱面，显示提示
6. 实现导航组件：
   - 侧边栏或顶部导航
   - 页面切换
7. 样式设计：
   - 使用 CSS 或引入 UI 库（如 TailwindCSS）
   - 暗色主题适配 BeatSaber 风格

# 数据类型定义

根据命令层返回的数据结构，定义前端 TypeScript 类型：

```typescript
interface PlayerInfo {
  id: string;
  name: string;
  avatar_url?: string;
  live_url?: string;
  alias?: string;
}

interface PlayerScore {
  player_id: string;
  score_id: number;
  leaderboard_id: string;
  map_key?: string;
  hash: string;
  mode: string;
  difficulty: string;
  accuracy: number;
  epoch_time: number;
}

interface Map {
  key: string;
  song_name: string;
  song_author_name: string;
  level_author_name: string;
  rating?: number;
  cover_url?: string;
  preview_url?: string;
}

interface Playlist {
  playlist_id: number;
  name: string;
  description?: string;
  playlist_image?: string;
  owner_name?: string;
  total_maps?: number;
}
```

# 完成总结

## 操作罗列

1. 安装依赖：TailwindCSS、PostCSS、Autoprefixer、@tailwindcss/postcss、React Router
2. 创建配置文件：`tailwind.config.js`、`postcss.config.js`
3. 创建全局样式：`src/index.css`（TailwindCSS 指令 + 暗色主题基础样式）
4. 创建类型定义：`src/types/index.ts`（PlayerInfo、Map、PlayerScore、Playlist 等）
5. 创建格式化工具：`src/utils/format.ts`（时间/精度格式化）
6. 创建布局组件：`src/components/Layout.tsx`、`src/components/Sidebar.tsx`
7. 创建基础 UI 组件：Modal、LoadingSpinner、EmptyState
8. 创建业务卡片组件：PlayerCard、PlaylistCard、MapCard、ScoreRow
9. 创建页面组件：Players、Playlists、MapSearch、ScoreLookup
10. 移动 TestPage.tsx 到 pages 目录
11. 更新 App.tsx 为 React Router 路由配置
12. 更新 main.tsx 引入 index.css
13. 删除旧 App.css

## 样式设计

使用 TailwindCSS 实现暗色主题，配色方案：
- 背景（主）：`#0a0a0f` (bs-dark-900)
- 背景（卡片）：`#1a1a2e` (bs-dark-800)
- 背景（侧边栏）：`#16213e` (bs-dark-700)
- 强调色：`#e94560` (bs-accent-primary，BeatSaber 红色)
- 霓虹绿：`#00ff88` (bs-accent-neon)

难度颜色映射：Easy(绿)、Normal(蓝)、Hard(黄)、Expert(红)、ExpertPlus(紫)
