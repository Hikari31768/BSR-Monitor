# 项目级

- 允许 git 读操作；未明确要求时禁止进行 git 写操作，不过允许建议

## 任务

- .tasks 文件夹下会有诸如 01-00-TaskName.md 的文件来描述任务内容
- 在任务执行过程中，如要创建未明确存放位置的临时文件，将其存放到诸如 .tasks/01-00 目录下；如果这些文件将作为正式项目的一部分，则将其妥善命名与放置
- 当显式确认任务完成后，在任务内容描述文件的末尾追加对本次任务的操作罗列、流程归纳、总结

## 项目

- .project 目录下保存了整个项目的：
  - 技术栈
  - 方案架构
  - 核心数据结构
  - 整体业务逻辑
  - 等等
- .project/Project.md 对项目进行整体描述，具体详细的说明分散到各自的独立 md 文件中，并做好链接索引
- 新建会话时，必须读取 .project/Project.md ，来建立对整个项目的整体认知
- 讨论中，如果达成共识要对上述内容扩充完善/做出改变/精简剔除，就对 .project 中的文件进行相应的更新
- 当涉及上述方面的代码实现被修改时，经显示确认后，对 .project 中的文件进行相应的更新

## 知识库

- .knowledge 目录下保存了项目相关的背景知识
- .knowledge/Knowledge.md 是整个知识库的目录
- 新建对话时，必须读取 .knowledge/Knowledge.md
- 应当积极查阅知识库
- 知识库由人工编写，允许提出质疑，但未明确要求时禁止增删改
